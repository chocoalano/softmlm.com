closed only with evidence (a test, a configuration check, or a documented

## Safeguards already in place

- Tests refuse to start unless the database is clearly a test database
  (`tests/support/database_guard.ts`, covered by `tests/unit/database_guard.spec.ts`).
- The test environment uses its own SQLite file (`tmp/test.sqlite3`).
- `nodemailer` is pinned to a patched 10.x through `overrides`; production must run Node.js 20 or newer. Do not downgrade it.
- QA fixtures are never seeded; QA accounts are created manually and removed after use.
